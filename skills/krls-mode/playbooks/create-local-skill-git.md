# create-local-skill-git

IMPORTANTE:

Es un error conocido que llames a la carpetea `../skill` en vez de `../skills`.

El objetivo de este playbook es crear la skill git local en la que se guarde las tablas con las convenciones de nombres ramas y mensajes de commits. Primero crea unas tu con todas las opciones e itera sobre estas tablas hasta que el usaurio te de el visto bueno.

Posterioremente a tener las tablas de convenciones de git, obligatoriamente tienes que solicitar la lista de pasos a seguir cuando se cierra una rama, es decir cuando se termina un objetivo (solucionar bug, fin desarrollo feature...). Y también lo tendrás que poner en la nueva skill de git que crees local.

IMPORTANTE, antes de crear la skill, vuelve a pedir la validación del usuario. Itera hasta que te de el visto bueno, cuando lo tengas, VERBATIM creas la skill.
